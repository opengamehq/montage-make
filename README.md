# opengame-montage-make

Build a gameplay montage from its plan, for any game, genre or engine, at any capture tier from a film build to live high-frame-rate capture. Covers the agent team with relays and bounded waits, film-build hooks or replay passes, takes as code with eased speed keys on the beat grid, payoff cinematics from the same run, offline take checks, and a resumable cut chain that delivers read back.

It is one of the [OpenGame](https://opengame.io) agent skills, which teach a coding agent such
as Claude Code, Codex, Cursor or OpenCode to build a browser game and put it online.

## Install

```bash
npx skills add opengamehq/montage-make
```

The skill installs under its own name, `opengame-montage-make`. Every OpenGame skill, each under its own
name, installs from [opengamehq/opengame](https://github.com/opengamehq/opengame):

```bash
npx skills add opengamehq/opengame
```

How the skills fit into making and shipping a game is at [docs.opengame.io](https://docs.opengame.io).
